# Built-in sounds

audio input. Our own recordings or CC0 only, never Bastl's SAMPLES.bin.

For each sound keep the source file, its licence and where it came from in a
line below. The packing script (planned) writes Wave Bard's open `k2wb` format
(`code/src/apps/WaveBard/WAVE_BARD_FORMAT.md`).
